
================================================================================
HYPOTHESIS 2: Activation PATTERNS (%MVC) ACROSS EXERCISE PHASES
================================================================================

HYPOTHESIS:
Cyclists in the high-Activation group will exhibit different EMG amplitude (%MVC)
patterns across phases than those in the low-Activation group.

--------------------------------------------------------------------------------
METHODS
--------------------------------------------------------------------------------

A two-way mixed ANOVA was conducted for each muscle with:
- Within-subjects factor: Phase (5 levels: Warmup, Second Threshold, VO₂max, WanT, Cooldown)
- Between-subjects factor: Activation Group (2 levels: High-Activation, Low-Activation)
- Dependent variable: Mean %MVC

Post-hoc comparisons used Bonferroni correction.
Effect size for phase effect: Kendall's W (from Friedman test)
Effect size for ANOVA: Partial eta-squared (η²p)

Participants were classified into High-Activation (n = 16) and Low-Activation 
(n = 43) groups using k-means clustering (k = 2).

--------------------------------------------------------------------------------
RESULTS
--------------------------------------------------------------------------------

PHASE EFFECT:
Significant main effects of phase on %MVC were found for 7/8 muscles.
The average effect size (Kendall's W) was 0.382, indicating a 
medium effect.

Kendall's W by Muscle:
  • MTL: χ²(4) = 112.93, p < .001, W = 0.495 (Medium)
  • MTR: χ²(4) = 114.24, p < .001, W = 0.510 (Large)
  • SCML: χ²(4) = 105.38, p < .001, W = 0.462 (Medium)
  • SCMR: χ²(4) = 86.90, p < .001, W = 0.388 (Medium)
  • STL: χ²(4) = 55.75, p < .001, W = 0.245 (Small)
  • STR: χ²(4) = 29.50, p < .001, W = 0.132 (Small)
  • UTL: χ²(4) = 107.44, p < .001, W = 0.471 (Medium)
  • UTR: χ²(4) = 80.54, p < .001, W = 0.353 (Medium)


GROUP EFFECT:
Significant main effects of Activation group were found for 5/8 muscles.

PHASE × GROUP INTERACTION:
Significant interaction effects were found for 2/8 muscles.

Significant interactions:
  • SCML: F(1,80) = 8.34, p = 0.0017, η²p = 0.132
  • SCMR: F(2,95) = 10.00, p = 0.0002, η²p = 0.156
